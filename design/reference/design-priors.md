# Design Priors

Named lenses to reason *from* when shaping or critiquing a design. The rule: **apply the principle, don't mimic the voice.** Cite the prior that justifies a decision instead of asserting taste — "this groups by proximity, Tufte" beats "this feels cleaner." Use during Shape, Taste, critique, and design-lab direction-picking.

## The Roster

| Prior | The lens it gives you |
|------|----------------------|
| **Edward Tufte** | Maximize data-ink. Remove everything that isn't information. Small multiples beat one busy chart. No chartjunk. |
| **Richard Saul Wurman** | Organize by LATCH — Location, Alphabet, Time, Category, Hierarchy. Anxiety comes from not understanding, not from volume. |
| **Dieter Rams** | Less, but better. Good design is unobtrusive — it serves the content and gets out of the way. |
| **Massimo Vignelli** | Discipline through a tight system: few typefaces, a strict grid, a fixed palette. The constraint *is* the design. |
| **Christopher Alexander** | Pattern languages — recurring solutions compose into a coherent whole with "quality without a name." |
| **Don Norman** | Affordances and signifiers. Map controls to outcomes. If the user errs, the design failed — not the user. |
| **Jakob Nielsen** | Heuristics, plus the reality that users spend most of their time on *other* sites — meet conventions before breaking them. |
| **Bret Victor** | Immediate, direct feedback. Show consequences *as* the user acts, not after they commit. |
| **Bill Buxton** | Design the *interaction*, not the screen. Sketch the experience; the artifact is downstream. |
| **Susan Kare** | Iconography as language — clarity at small sizes, personality from precision, one coherent visual vocabulary. |

## How to Use

- Proposing a direction? Name the prior it leans on. Killing one? Name the prior it violates.
- Priors conflict on purpose: Tufte's density vs Rams's restraint, Nielsen's conventions vs distinctive taste. The dials (DESIGN_VARIANCE / VISUAL_DENSITY) decide which prior wins for *this* project — don't average them into mush.
- A prior is a lens, not a destination. Rams + Vignelli applied without judgment produce the same Swiss minimalism everyone ships. Use the lens to see; then make the call.

---

**Avoid**: citing a prior as decoration ("inspired by Dieter Rams") without applying it. Reasoning from a prior whose value fights the project's dials.
